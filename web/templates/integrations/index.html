Integrasi Google Sheets

Aiven MySQL adalah sumber data utama. Tarik data ke Google Sheets lewat Apps Script menggunakan endpoint read-only berikut (tanpa API key, JSON):

GET /api/apps-script/summary GET /api/apps-script/classifications GET /api/apps-script/classifications/list GET /api/apps-script/classifications/{kode}/archives GET /api/apps-script/statistics/top GET /api/apps-script/search?q=kata
Contoh script untuk Google Sheets 
function tarikData() {
  const url = '{{.AppURL}}/api/apps-script/summary';
  const res = UrlFetchApp.fetch(url);
  const data = JSON.parse(res.getContentText());
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  sheet.getRange(1, 1).setValue('Total Arsip');
  sheet.getRange(1, 2).setValue(data.total);
}
