Cara mendapatkan Client ID:
  1. Buka Google Cloud Console → buat/ pilih project.
  2. Aktifkan API Google Drive API (menu APIs & Services → Library).
  3. Buat OAuth Client ID tipe Web application (menu Credentials → Create Credentials), tambahkan http://localhost:8080 (atau URL aplikasi) ke Authorized JavaScript origins.
  4. Salin Client ID ke kolom di bawah. Folder ID opsional (kosongkan untuk upload ke root Drive).
