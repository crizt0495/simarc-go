Backup Cloud (Offsite). Database lokal tetap menjadi sumber utama dan aplikasi tetap berjalan penuh walau internet mati. Setiap hari SIMARC menyalin (mirror) database ke database cloud MySQL gratis (mis. Aiven for MySQL) dan menyalin berkas arsip ke object storage S3-compatible (mis. Cloudflare R2 / Backblaze B2). Salinan ini bersifat offsite — hanya tujuan pemulihan bila server rusak, bukan untuk dibaca aplikasi.

Database Cloud (MySQL)

Isi dengan kredensial database MySQL cloud gratis. Untuk Aiven, buka dashboard layanan → Connection information.

Object Storage (Berkas Arsip)

Salinan berkas arsip. Bisa ke object storage S3-compatible (R2: https://<account_id>.r2.cloudflarestorage.com, B2: https://s3.<region>.backblazeb2.com) atau ke rclone remote yang sudah dikonfigurasi (mis. Google Drive) — tanpa perlu akun baru.

Nama remote hasil rclone config di server (mis. gdrive).
