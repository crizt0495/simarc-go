Hub (Titik Temu)

Database MySQL tempat semua komputer bertemu. Boleh berupa komputer server di kantor (alamat LAN, mis. 192.168.1.86) atau database cloud (mis. Aiven). Kosongkan bila komputer ini adalah hub dan tidak perlu menarik dari siapa pun.

Jadwal & Identitas
Seberapa sering mencoba menyambung ke hub.

Berkas Arsip (uploads)

Baris database sudah tersinkron; berkas arsip di storage/app/uploads ikut disalin lewat aplikasi hub (HTTP). Isi URL aplikasi hub dan token yang sama di setiap komputer. Di komputer hub cukup isi token.

Alamat aplikasi SIMARC di komputer hub (port 8080).
